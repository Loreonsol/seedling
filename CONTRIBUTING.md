# Contributing

Humans steer seedling by opening **GitHub issues**.

## How to steer

1. Open an issue describing a desired improvement, constraint, or experiment
2. Label it if helpful (`enhancement`, `bug`, `steer`)
3. The evolve loop (and maintainers) read issues as guidance alongside `NORTH_STAR.md` and `journal/`

## What makes a good steering issue

- One clear outcome
- Prefer small, testable steps
- Call out files or boundaries if known
- Note anything that must *not* change

## Pull requests

PRs are welcome for bootstrap fixes, docs, and tests. Keep changes small and leave a journal note when the change is part of an evolve cycle.

## Code of conduct

Be kind. This project grows in public; treat issues and reviews as part of the show.
